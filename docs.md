# Design system notes

VoicePreserve uses a compact design token set in `src/styles/globals.css`:
- calm neutral backgrounds
- green primary actions for trust and editorial focus
- warm amber alerts for semantic warnings
- high contrast text and controls for accessibility

Component conventions:
- `.panel` for surface containers
- `.btn-primary` for key flow actions
- `.warning-box` for meaning-preservation alerts
- `.diff-card` for sentence-level review units
